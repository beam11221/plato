## 1. Step 0 audit (summary)

**Where training times came from.** `build_fleet.py` wrote a static sleep table. The anchor entered on both sides:
- the simulator side, through `anchor_scale`;
- the predictor side, through `gpu_tier_sleep.predictor_scale`.

Every config generator wrote `anchor_sleep = 15`.

**PLATO's sleep is per client, not per dispatch.** `Config.client_sleep_times` is indexed by `client_id`. The per-dispatch override is the hook `process_client_info`. It rewrites `report.training_time` to `T_train_true + T_up_true` and zeroes `processing_time` before PLATO computes the finish time.

**T_round, τ̂ and s(·).**
- T_round uses the queue kernel `mean(T̂)/C`. At startup it is taken over the fleet; afterwards it is recomputed live over the busy set.
- τ̂ is the two-phase residual count.
- s(·) receives τ̂ in rounds.

**Clock reconstruction.** The old `gpu_tiers_dataset/clock_reconstruction.py` assumes one static sleep per client and an immediate refill of every freed slot. It is replaced here by `wen_clock_replay.py`.

**Old Stage 0.** `sumo_close_loop/stage0_filter.py` used `v_max = 19.44` m/s and had no upload term.

## 7. Deviations from the prompt

1. **The bundle zip is not on this machine.** The zip's sha256 cannot be checked. Instead, `manifest.yaml` is pinned, and all 19 per-file sha256 values it lists are verified; they match. The zip is verified as well whenever one is supplied.
2. **The SUMO ADR text is not in the bundle.** The manifest references it, but the file was not shipped, so ADR-0005 is a placeholder. This repo also had ADR-0001…0004, not 0001…0006 as the prompt says.
3. **The global position test was replaced.** Each SUMO wrap costs one 0.1 s step per lap (not a 0.1 m clamp), so `(x0 + V·t) mod 2000` drifts by up to about 1 km. The test checks the per-lap form within 0.2 m instead, and a second test pins the global drift.
4. **The trace starts at t = 1 s.** For t ∈ [0, 1), x is extrapolated backwards with V_k.
5. **The fading RNG key is `(seed, client, round, k)`.** In S2, a lost update holds the round counter, so the same client can be dispatched again under the same round number; `k` stops it from replaying the same draw.
6. **A disjoint Dirichlet partition sampler was written.** PLATO's `noniid` sampler reuses images across clients. The new sampler's Sinkhorn step moves each client's label distribution away from its Dirichlet draw by a mean total-variation distance of 0.063.
7. **The Stage 0 fallback rule was kept.** It never triggered in the smoke run.
8. **Open issue: E_max blocks the cpu arm completely.** Its Ê is above 600 J in every tier (931 / 1,746 / 2,561 J), so cpu + Stage 0 (run plan #13) would fall back on every cycle. This needs a decision before that cell is run.
9. **Other notes.**
   - The `location_only` switch is implemented but has not been run.
   - The `observed` arm keeps τ = 0.01 as the prior for unseen vehicles.
   - The old tier CSVs are unchanged; the 2.2 GHz clocks live in the new `tiers_wen.csv`.
   - `plato/` core is untouched.
   - The environment was fixed with `uv sync` plus fvcore.
   - Checkpoints from the smoke runs were deleted; logs and results are kept.
