4. **How TTA is computed now** (`sumo_open_loop/analyze_stage7.py`, `curve_stats`, lines 380–395; `rolling_median` 375): the evaluations are smoothed with a **centred rolling median over 11 evaluations** (`SMOOTH_WINDOW = 11`, truncated at the ends), and TTA is the reconstructed sim-time of the **first evaluation whose smoothed value ≥ target**. No interpolation. So TTA is already smoothed, and it moves in 10-round steps. That method is E0 here; the reimplementation matches the existing `tta_h_*` on every run (max difference 0.0e+00 h).
